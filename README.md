# 💍 WeddingMoneyManager

결혼 준비 과정에서 발생하는 다양한 비용을 체계적으로 관리하기 위한 결혼 비용 관리 프로그램입니다.

결혼 준비 비용, 예산, 지출 내역을 한눈에 확인하고 관리할 수 있도록 제작한 개인 프로젝트입니다.

---

## 📌 프로젝트 소개

결혼 준비 과정에서는 예식장, 혼수, 가전, 가구, 여행 등 다양한 항목에서 많은 비용이 발생합니다.

WeddingMoneyManager는 이러한 지출을 쉽게 기록하고 관리하여:

* 전체 결혼 비용 확인
* 항목별 지출 관리
* 예산 대비 사용 금액 확인
* 결혼 준비 과정의 금융 데이터 관리

를 목표로 개발했습니다.

## ⚙ 실행 방법

### 1. 저장소 다운로드

```bash
git clone https://github.com/username/WeddingMoneyManager.git
```

### 2. 가상환경 생성

```bash
python -m venv venv
```

### 3. 가상환경 활성화

Windows:

```bash
venv\Scripts\activate
```

### 4. 패키지 설치

```bash
pip install -r requirements.txt
```

### 5. 실행

```bash
python app.py
```
